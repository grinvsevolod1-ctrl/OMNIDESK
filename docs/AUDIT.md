## Мобильный / PWA / адаптив (фаза 4)

Скриншоты пользователя (Android, standalone-PWA) показали конкретные баги.
Разобраны shell, инбокс куратора, общий `thread-pane`, композер, список
сообщений. Найдены и **исправлены** три корневые причины:

### P0-mobile — ИСПРАВЛЕНО

- [x] **Клавиатура «швыряет» экран вверх, всё чёрное** (`app/layout.tsx`). Во
  viewport не был задан `interactiveWidget`. Дефолт `resizes-visual` заставляет
  Android-Chrome ОВЕРЛЕить клавиатуру и прокручивать `fixed inset-0` shell вверх
  → лента уходит за экран, видно чёрный фон body. **Фикс:**
  `interactiveWidget: 'resizes-content'` — клавиатура сжимает layout-viewport,
  `100dvh`/shell садятся ровно над клавиатурой. iOS этот ключ игнорирует — там
  работает visualViewport-оверрайд (ниже).
- [x] **Чёрный «подвал» под композером** (`components/dashboard-shell.tsx`). JS
  писал `--app-vh = visualViewport.height` всегда; после закрытия клавиатуры
  значение оставалось заниженным → `fixed`-shell короче экрана, снизу просвечивал
  `bg-background`. **Фикс:** высоту пиним ТОЛЬКО когда клавиатура реально открыта
  (`innerHeight − visualViewport.height > 120`), иначе `--app-vh` очищаем и отдаём
  управление `100dvh`. Стухшее короткое значение больше не появляется.
- [x] **Текст пузыря обрезан справа** (`components/manager/inbox/message-list.tsx`,
  общий для менеджера и куратора). Flex-цепочка колонка→триггер-меню→пузырь без
  `min-w-0`/`max-w-full`: длинная строка с `white-space: pre-wrap` раздувала
  пузырь шире колонки, а `overflow-x-hidden` ленты его срезал (текст не
  переносился). **Фикс:** `min-w-0` на колонке `max-w-[80%]` + `max-w-full` на
  пузыре — строка переносится внутри 80/70 % ширины.

### Проверено и признано корректным

- Фундамент адаптива в порядке: `viewportFit: cover`, safe-area утилиты
  (`pt-safe`/`pb-safe`/`px-safe`), `h-dvh-safe` (100dvh с 100vh-фолбэком),
  `overscroll-behavior-y: none` в standalone, touch-hitbox 44px для icon-кнопок,
  шрифт инпутов ≥16px (нет авто-зума iOS), `apple-mobile-web-app-capable`.
- Инбокс менеджера/куратора: список↔тред переключаются по `activeId`
  (`hidden md:flex`), шапка диалога уходит в портал единственной шапки shell —
  двойных заголовков на мобиле нет.
- Композер: пилюля `flex-1`, кнопка send/mic `shrink-0` — на сужении не
  вытесняется. `pb-safe` кроет home-indicator.

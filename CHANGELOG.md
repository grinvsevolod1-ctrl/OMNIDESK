# Changelog

## 2026-09-26 — God-панель: безвозвратное удаление диалогов

### Что сделано
- Добавлена новая вкладка **«Удаление»** в god-панель с максимально гибким поиском по всем диалогам системы и возможностью полностью, безвозвратно удалить любой диалог (или несколько сразу).
- Поиск работает по любым критериям: текст (имя/логин/телефон/email контакта, заголовок диалога, содержимое сообщений, внешний id), канал, назначенный менеджер, статус диалога, наличие непрочитанных, диапазон дат последней активности.
- Удаление каскадное и необратимое: чистит сам диалог и все связанные записи (сообщения, вложения/медиа, черновики, прочтения, назначения, теги и т.п.) в одной транзакции — по образцу существующих purge-скриптов.
- Перед удалением — обязательное подтверждение с явным предупреждением о необратимости; действие пишется в audit-trail (`audit()`).

### Где
- `app/actions/admin-secret/dialogs.ts` — новые server actions: поиск (`secretSearchDialogsAction`) и безвозвратное удаление (`secretPurgeDialogsAction`).
- `app/actions/admin-secret.ts` — реэкспорт новых экшенов из barrel-файла.
- `components/admin/secret-dialogs-tab.tsx` — UI вкладки: панель фильтров, список результатов с мультивыбором, диалог подтверждения удаления.
- `components/admin/secret-dashboard.tsx` — регистрация вкладки «Удаление» (иконка `Trash2`, секция `dialogs`, ленивый импорт и рендер).

### Как проверено
- `npx tsc --noEmit` — проходит без ошибок (в т.ч. по новым файлам `dialogs.ts` и `secret-dialogs-tab.tsx`).
- Вкладка доступна только внутри god-панели за существующим fail-closed гейтом (`requireAdmin`), путь `/wijegniwjgwjog`.
